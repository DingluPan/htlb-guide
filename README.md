# 高性价比人生指南 · 深度解读版

基于开源项目 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 整理的**深度解读网页版**。

**在线阅读**：https://dinglupan.github.io/htlb-guide/

## 是什么

原书共 **34 章、676 条**生活决策建议，覆盖健康、安全、法律、理财、家庭、职场等。本版将全部条目整理为单页网页，并做了增强：

- **吸顶目录**：一级=章节索引，二级=条目索引；默认展开约 1/3 屏，可收起/放大，点条目直达
- **条目卡片**：保留原书「说人话 / 关键收益 / 成本 / 备注」结构，附加彩色标签
- **原文出处**：每条附 GitHub 原文章节链接
- **性价比天花板标记**：证据 A + 不花钱 + 收益大的条目带红色边框，一眼锁定

## 标签说明

| 标签 | 含义 |
|---|---|
| **证据 A** | 最硬的证据：荟萃分析（把多项随机试验合起来算）或大规模随机对照试验（RCT） |
| **证据 B** | 有研究支持：队列研究、单项研究或官方统计，方向可信但数字可能混有干扰因素 |
| **证据 C** | 共识/经验：权威机构指南或常识性结论，缺乏硬实验数据 |
| **⚠ 争议** | 学术界或实务界尚有分歧的条目，看备注再决定 |
| **不花钱** | 成本标签：钱=0，纯行为改变 |
| **不用毅力** | 不需要长期意志力维持，做一次或顺手完成 |
| **收益大** | 原书判定收益档位为「大」（另有中/小两档，未标即默认） |

> 证据等级与性价比判断均为**原作者观点**（原书有完整来源引注），仅供参考，不构成医疗/法律/投资建议。

## 使用建议

原书理念：这是一份**按性价比排好的备选单，不是任务清单**。挑走一两条就算数。

快速上手：翻到任意章，优先看**红框条目**（证据硬 + 不花钱 + 收益大），当天能做先做。

## 与原书的关系

- 原书正文与标签来自原仓库 `book/` 下 34 个 markdown 文件，本仓库仅做格式转换与网页化，**未增删条目**
- 各章开头的「📌 本章解读」为整理者添加
- 原书更新后，重新运行整理脚本即可同步
